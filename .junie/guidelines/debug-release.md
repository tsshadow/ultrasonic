# Create Debug Release

Follow these steps when asked to create a debug release.

## 1. Run Debug Script
- Run `./install.sh debug` (or just `./install.sh` as it defaults to debug).
- This will:
  - Increment the build number (versionCode).
  - Build the application in debug mode.
  - Publish and deploy the debug build locally/to the test environment.
- Make sure that the debug build is published to apk.teunschriks.nl
