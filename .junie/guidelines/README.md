# Project Guidelines (AI Skills)

This directory contains guidelines for Junie to follow when performing specific tasks in this project.

## Available Workflows

- [Create Release](release.md): Steps for analyzing changes, updating the changelog, and running the release script (`./install.sh [patch|minor|major]`).
- [Create Debug Release](debug-release.md): Steps for building and publishing a debug version of the app (`./install.sh debug`).
- [Commit and Publish](commit-and-publish.md): Steps for grouping local changes, updating the `[Unreleased]` section of the changelog, and committing.

When asked to perform one of these tasks, Junie should refer to the corresponding guideline to ensure consistency with the project's standards and scripts.
