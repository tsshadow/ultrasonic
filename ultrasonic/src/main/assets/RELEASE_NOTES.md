# Release Notes - Ultrasonic 5.1.0

## Version 5.1.0 (2026-07-04)

This update focuses on keeping you up-to-date with the latest improvements and providing better visibility into what's new.

### Features
- **Auto-Update System**: Ultrasonic can now automatically check for updates on startup. You can also manually check for updates via the "Check for Updates" button in the About screen. (Note: Requires a compatible `apk-hoster` server).
- **In-App "What's New"**: A new popup will automatically greet you after an update, highlighting the most important changes so you never miss a feature.
- **Integrated Changelog**: You can now view the full history of Ultrasonic development directly within the app from the About screen.

### Improvements & Fixes
- **APK Download Fix**: Resolved an issue where APK files could sometimes be downloaded with an incorrect file extension (as ZIP files) when using the internal hosting service.
- **User Interface**: Added a dedicated "Check for Updates" button to the About screen for easier manual checks.
